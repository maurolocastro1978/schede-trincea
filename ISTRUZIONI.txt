SCHEDA SINTETICA DI TRINCEA – PROTOTIPO v1
Cisterna–Valmontone | Lotto 3

CONTENUTO
index.html: applicazione mobile per compilare, salvare, riaprire ed esportare schede.
manifest.webmanifest, sw.js, icon.svg: installazione come web app offline (PWA).

COME PROVARLA SUL COMPUTER
Aprire index.html in Chrome. Se il browser consente IndexedDB per file locali, il salvataggio funzionera'.
Per un test affidabile utilizzare un server locale, ad esempio: python -m http.server 8000
Poi visitare http://localhost:8000.

COME USARLA SULLO SMARTPHONE
L'app deve essere pubblicata su un sito HTTPS (es. spazio web aziendale o hosting statico).
Aprire il link sullo smartphone e usare la voce del browser "Aggiungi a schermata Home" / "Installa app".
Aprirla una prima volta mentre c'e' connessione; in seguito puo' funzionare offline.
ATTENZIONE: aprire il file HTML come allegato sul telefono NON equivale a installare l'app offline.

DATI E SICUREZZA
Tutti i dati, incluse le fotografie, vengono salvati nel browser del singolo dispositivo mediante IndexedDB.
Non esiste sincronizzazione con altri archeologi, login, archivio cloud o backup automatico.
Le modifiche non salvate manualmente possono andare perse.
Utilizzare Archivio locale > Esporta backup JSON regolarmente, conservando il backup altrove.
La cancellazione dei dati del sito/browser puo' eliminare tutte le schede locali.
La numerazione duplicata viene segnalata solo nell'archivio dello stesso dispositivo.
Il CSV esporta i dati della scheda ma non i file delle foto; il JSON comprende le foto.
Per la produzione sono necessari ulteriori test e un servizio di sincronizzazione.
