SCHEDA SINTETICA DI TRINCEA - VERSIONE 3, TEST CONFERMA RICEVUTA

1. PRIMA aggiornare Codice.gs in Google Apps Script usando il contenuto completo di Codice_Apps_Script_v3.gs.
   NON sostituire le proprietà script ARCHIVIO_FOLDER_ID e ARCHEOLOGI_TOKEN: rimangono quelle già configurate.
2. Apps Script: Esegui il deployment > Gestisci deployment > Modifica > Versione: Nuova versione > Esegui il deployment.
   Mantenere lo STESSO indirizzo /exec del deployment esistente.
3. SOLO DOPO caricare su GitHub i 5 file dell'app (index.html, sw.js, manifest.webmanifest, icon.svg, ISTRUZIONI.txt).
   NON caricare su GitHub il file Codice_Apps_Script_v3.gs, che è destinato solo all'editor Apps Script.
4. Aprire l'app dal telefono quando connesso, verificare la versione v3, compilare una scheda fittizia e sincronizzarla.
5. Il pulsante segnala Sincronizzata SOLO dopo avere letto una conferma del server.
   Se non arriva conferma, la scheda rimane salvata e non confermata.

NOTE IMPORTANTI
- Usa SOLO dati di prova fino alla validazione del flusso e della sicurezza.
- Non mettere mai il codice personale nel repository GitHub, nei log o nelle chat.
- Il codice personale resta solo in memoria durante la sessione: reinserirlo dopo la riapertura.
- Fotografie grandi possono superare i limiti di Apps Script; è necessaria una prova dedicata.
- Le ricevute server restano in cache 6 ore: la conferma è immediata, non un indice permanente.
- L'archivio locale resta indipendente da Drive e non viene cancellato.
- La versione 3 mantiene le schede esistenti nel database locale sullo stesso dominio.
